# GitHub connection

The platform reaches GitHub through a **GitHub App** of the org. Only `platform-admins` set it up.

<div class="grid cards" markdown>

-   :material-plus-circle-outline: **New App**

    ---

    The org has no App for the platform yet. The platform creates it from a manifest and you install it on the org.

    [:octicons-arrow-right-24: Connect the platform to GitHub](create-app.md)

-   :material-key-change: **Reuse an existing App**

    ---

    The org already has the App, for example from a cluster recreated from scratch. You give the platform a new key for it.

    [:octicons-arrow-right-24: New key for an existing App](existing-app/new-key.md)

</div>

Both paths end at [Verify the GitHub connection](verify.md).
