# GitHub connection

The platform reaches GitHub through a **GitHub App** of the org, such as `wasp-foundry-platform`. Only `platform-admins` set it up.

Pick the path that matches the org:

| The org… | Path |
|---|---|
| has no App for the platform yet | [New App](create-app.md): the platform creates and installs it |
| already has the App, for example from a cluster recreated from scratch | [Reuse an existing App](existing-app/new-key.md): a new key for it |

Both paths end at [Verify the GitHub connection](verify.md).
