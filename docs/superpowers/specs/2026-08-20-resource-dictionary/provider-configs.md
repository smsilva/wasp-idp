# provider-configs

|  |  |
|---|---|
| **Description** | Remote ProviderConfigs (helm and kubernetes) that point to the new cluster (spoke) using the kubeconfig Secret generated by `cluster-auth`.<br><br>They are what lets the hub's Crossplane install Releases (Istio, controllers) and Objects (echo, issuers) inside the spoke.<br><br>Held at teardown while there are still in-cluster Releases/Objects. |
| **Provider** | provider-helm / provider-kubernetes |
| **Kind** | ProviderConfig ×2 |
| **Layer** | 03 · eks |
| **Dependencies** | `cluster-auth` (kubeconfig Secret) |
| **Teardown** | held by the in-cluster Releases/Objects |

## Examples

- `helm` — `<full>-helm` (provider-helm)
- `kubernetes` — `<full>-k8s` (provider-kubernetes)
