Keycloak theme · B — Split

Tela dividida: à esquerda, o contexto — o que é a plataforma e o terminal que está pedindo o login —; à direita, a ação. A coluna da esquerda conecta o navegador ao comando que o usuário acabou de rodar, que é como quase todo login acontece (platform login). Exige um template.ftl próprio para o layout; os parciais de formulário continuam os do keycloak.v2. Abaixo de 860 px a coluna de contexto vira uma faixa no topo.
