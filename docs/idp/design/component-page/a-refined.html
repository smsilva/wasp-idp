Notas de design (proposta A — Refined)
  • A descrição sobe para o header e sai do card: hoje ela aparece duas vezes (About e Description).
  • Breadcrumb com a cadeia Domain → subdomain → System no lugar de "Catalog" sozinho.
  • Abas com contagem: dá para ver que APIs está vazia sem abrir.
  • v2: ambientes viram a aba Environments (resumo + 10 primeiras ArgoCD Applications, problemas no topo, link para o ArgoCD), pensada para centenas de Applications.
  • v2: a aba de docs fica só como aba; saem o botão Docs do header e o link TechDocs do card Links.
  • v2: lifecycle vai para o fim da linha de chips.
  • v2: Latest commit linka o commit real e cruza o SHA com a tag da imagem nos clusters.
  • Dependências agrupadas por papel (Data / Runs on): clusters não se misturam com banco e fila.
  • Grafo de relações compacto (170px) com link para o grafo completo.
  • Seções vazias somem (Depends on components, Has subcomponents); estado vazio de APIs ensina o próximo passo.
  • Kubernetes mostra pod, imagem e restarts sem expandir; card de promoção explica o próximo passo do gitops.
  • Dados novos: último commit via GitHub API a partir de github.com/project-slug; Applications via plugin do ArgoCD.
