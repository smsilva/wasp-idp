# Who am I

```bash
platform whoami

platform whoami --output json
```

!!! note
    The `sub` is the user's **immutable ID** in Keycloak; it is what goes into the audit trail.

!!! tip
    An AI agent can ask the platform the same question through its MCP server. [Connect an AI agent](../agents/connect.md), near the end of the walkthrough, sets it up once the environment and the catalog exist.
