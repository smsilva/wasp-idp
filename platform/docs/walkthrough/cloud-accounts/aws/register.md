# Register the account

Register an account by the **role the platform will assume** in it, and the regions the platform may use; environments go to the first one:

```bash
platform cloud account add demo-aws \
  --role-arn arn:aws:iam::<account>:role/platform \
  --region us-east-1
```

``` { .text .output title="output" }
✓ cloud account demo-aws added (pending)
Trust policy of arn:aws:iam::<account>:role/platform:
{ … "sts:ExternalId": "<generated by the API>" … }
Apply it as the trust policy of the role, then run: platform cloud account verify demo-aws --wait
```
